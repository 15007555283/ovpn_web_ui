首个正式版本，提供单个 Go 二进制部署的 OpenVPN 管理后台。

### 功能与调整

- 支持管理员登录、客户端证书管理、配置下载、路由管理、在线状态和操作审计。
- 按模块保存 JSONC 数据到 `data/db`，演示生成文件独立放在 `data/fake`；支持旧数据自动迁移。
- 配置支持中文注释，区分演示与生产模式，可指定 OpenVPN 配置、PKI、状态文件及管理命令。
- 生产仪表盘读取真实 OpenVPN 服务、证书和在线状态。
- Vue 页面按布局、业务页面、组件和公共请求拆分；Go 入口移至项目根目录。
- 默认安装到 `/data/ovpn`，支持 `ovpn-cli --config`、服务启停和 GitHub Release 更新。

### 安装与更新

下载对应架构的 `.tar.gz` 安装包，解压后按 README 执行 `deploy/install.sh`，配置 HTTPS 反向代理。后台默认只监听 `127.0.0.1:8080`，由 Nginx 提供 443 访问。

已按当前目录结构安装的服务器可执行：

```sh
ovpn-cli update --check
sudo ovpn-cli update
ovpn-cli version
```

附件包含 Linux amd64、arm64 二进制、完整安装包及 `checksums.txt`。安装包不包含运行配置、管理员数据、证书和私钥。

### 升级说明

- 升级前备份完整数据目录和 OpenVPN PKI；自动迁移后的数据不应交给旧版程序直接读取。
- 旧版 `/usr/local/bin/vpn-admin` 安装布局需按部署文档迁移配置、数据和 systemd 服务；二进制自动更新不迁移部署布局。
- WebUI 需要已有可用的 OpenVPN / EasyRSA 环境；安装和更新后台不会自动安装 OpenVPN。
- 已完成 Go 竞态测试、静态检查、前端类型检查及构建；真实 VPN 客户端连接与分流仍需在使用环境验证。
