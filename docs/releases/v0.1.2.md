### 仪表盘

- 服务启动时间统一为 `YYYY-MM-DD HH:mm:ss`，保留服务器本地时间。
- 新增独立的「ovpn-cli 版本」卡片，显示当前运行版本。
- 进入仪表盘自动检查正式版，支持手动检查和查看发布说明；网络失败会明确提示。
- 提供更新方法弹窗，展示服务器更新命令及更新影响。

### 安装包

- 附带 Linux amd64、arm64 二进制、安装包和 SHA256 校验文件。
- 安装包包含 `scripts/install_ovpn.sh`，用于独立安装 OpenVPN；更新管理后台时无需运行该脚本。

### 更新

```sh
ovpn-cli update --check --version v0.1.2
sudo ovpn-cli update --version v0.1.2
ovpn-cli version
```

升级前备份配置、数据及 PKI。更新会短暂重启管理后台，保留现有配置、数据和 PKI，不重启 OpenVPN 服务。完成后刷新页面并重新登录。

已通过 Go 竞态测试、静态检查、前端类型检查及构建；本地浏览器验证了版本检查与更新说明弹窗。
