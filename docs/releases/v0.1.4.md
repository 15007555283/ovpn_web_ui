# v0.1.4

## 新增与调整

- 分流路由支持项目分组、全部项目筛选及规则归属调整；每组多地址仍展开为独立 OpenVPN 路由。
- 分流页面分为“规则配置”和“项目配置”两个 Tab，新增和编辑项目使用弹窗。
- 右上角新增圆形用户图标菜单，系统状态、系统设置、修改密码改为独立弹窗，退出登录收至菜单中。
- 系统设置仅保留配置修改，移除侧栏中的系统状态和系统设置入口。
- 移除配置应用记录展示、各页面手动刷新按钮及顶部演示模式提示。

## 数据兼容

新增独立 projects.jsonc，兼容现有版本 2 数据，旧规则默认为“未分组”。下一次数据写入会升级存储格式至版本 3。升级前请备份程序、配置和完整 data 目录；降级时需同时恢复匹配的旧数据备份，不能只替换二进制。

## 验证

Go 全量竞态测试、go vet、Vue 类型检查和前端生产构建通过。尚未完成本轮界面的浏览器交互验收。
